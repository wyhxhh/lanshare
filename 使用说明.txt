LanShare 局域网文件共享 — 使用说明（v0.2.1）
===============================================

【这是什么】
  一个免安装的单文件 exe：选定一个文件夹后启动 HTTP 文件服务，
  局域网内任何设备（电脑 / 手机 / 平板）用浏览器即可浏览、下载文件，
  支持整目录打包 ZIP 下载、断点续传、多人同时访问。

  特点：
  · 只读共享：访问者只能浏览/下载，不能上传或删除 —— 安全省心
  · 原生桌面界面 + 系统托盘常驻：关窗不退出，继续共享
  · 高并发：基于 Go net/http，每连接独立处理，百人同时下载无压力
  · 大文件友好：支持 Range 断点续传、流式打包（内存占用恒定）
  · 可设访问密码（可选）
  · 单文件运行，绿色免安装，不留注册表

【运行环境】
  Windows 10 / Windows 11（64 位）。无需安装任何依赖。

【快速上手】
  1. 双击 LanShare.exe 启动，出现主窗口；
  2. 点「浏览…」选择要共享的文件夹；
  3. （可选）设置端口（默认 8000）与访问密码；
  4. 点「启动服务」；
  5. 主窗口「访问地址」会列出本机局域网地址（可能多个），
     把形如  http://192.168.x.x:8000  的地址发给同事 / 用手机浏览器打开即可。

【手机 / 其它电脑如何访问】
  确保设备与共享电脑连接同一个局域网（同一路由器/交换机，或同一 Wi-Fi）。
  · 电脑：浏览器打开地址即可（推荐 Chrome / Edge / Firefox）
  · 手机：浏览器打开同一地址；文件较多时建议用「打包 ZIP」下载目录
  · 若访问地址带密码，打开后先输入密码（浏览器可勾选记住）

【Windows 防火墙提示（重要）】
  首次启动后若他人无法访问，通常是 Windows 防火墙拦截：
  1. 打开「控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙」；
  2. 点「更改设置」→「允许其他应用…」→ 选择本程序 LanShare.exe；
  3. 勾选「专用」（家庭/工作网络）即可；
     或临时关闭防火墙验证（测试完请重新开启）。
  （公司网络还可能受上网行为管理/交换机隔离限制，需联系网管放行）

【退出与托盘】
  · 关闭窗口 = 最小化到系统托盘（右下角图标），共享服务继续运行；
  · 彻底退出：右键托盘图标 →「退出 LanShare」（会先优雅停止服务）；
  · 程序只允许运行一个实例，重复双击会提示已在运行。

【隐藏与忽略】
  · 默认不显示以下划线点开头的隐藏文件（如 .git）与 Office 临时文件（~$*.docx）；
  · 界面可勾选「显示隐藏文件」或填「忽略规则」（如 *.tmp, node_modules）定制。

【常见问题】
  · 端口被占用？换一个端口再启动（提示会说明占用原因）。
  · 看到「打包失败清单 _打包报告.txt」？个别文件被占用/删除/指向共享外时会被跳过
    并写入包内报告，不影响其余文件下载。
  · 中文文件名乱码？现代浏览器/解压工具（Win10+ 自带、Bandizip、7-Zip 新版）
    均正常；过旧的工具可能不支持 UTF-8 文件名。
  · 设置的密码保存在哪里？%APPDATA%\LanShare\config.json（本机用户目录）。
    想重置：删除该配置文件或直接改界面密码重新启动即可。

【安全说明】
  · 传输为明文 HTTP，仅建议在可信内网使用，请勿在公共网络开放；
  · 共享为只读，不暴露共享目录之外的任何文件（含符号链接越界防护）；
  · 建议对敏感资料设置访问密码；
  · 不使用时请点托盘「退出 LanShare」停止服务。

【校验（可选）】
  发布包附带 .sha256 校验文件，可用
    certutil -hashfile LanShare-v0.2.1-win64.exe SHA256
  比对哈希，确认文件完整未被篡改。

【卸载】
  直接删除 exe 即可（无安装痕迹）。个人配置位于 %APPDATA%\LanShare\，可一并删除。
